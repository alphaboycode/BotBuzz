04 / 09

Smart Contract Engineering

Built with OpenZeppelin 5.x ReentrancyGuard and Checks-Effects-Interactions pattern.

// SPDX-License-Identifier: MIT pragma solidity ^0.8.24; contract BotBuzz is ReentrancyGuard { struct Post { uint256 id; address author; string title; // 1 - 100 bytes string description; // 1 - 500 bytes uint64 createdAt; uint256 likes; uint256 dislikes; uint256 totalTips; } // Direct tip transfer with Reentrancy protection function tip(uint256 postId) external payable nonReentrant { if (msg.value == 0) revert ZeroTipValue(); Post storage post = _posts[postId]; if (msg.sender == post.author) revert CannotTipOwnPost(); post.totalTips += msg.value; emit Tipped(postId, msg.sender, post.author, msg.value); (bool success, ) = post.author.call{value: msg.value}(""); if (!success) revert TipTransferFailed(); } }

🛡️ Multi-Level Reentrancy Defense

All state mutations (tipping, voting, vote removal) are shielded with OpenZeppelin's ReentrancyGuard, thwarting reentrancy attempts from malicious contracts.

⚡ Paginated Newest-First Queries

getPosts(offset, limit) returns newest posts first with full boundary clamp safety, handling zero total, offset out-of-bounds, and zero limit gracefully.

🧪 Invariant Fuzz Testing (256 Runs)

Fuzz testing simulates random sequences of 15 actions across 4 distinct voters to mathematically prove likes/dislikes never underflow or desync.
